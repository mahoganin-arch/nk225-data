## 1. この期間に決めた方針
- 候補群（約95万件）を①乖離幅の安定性②最悪の1回③決済の選び方への強さで絞る当初案は、検証の結果「機能しない」と判断（下記2）。ただしテーマ（窓×条件）はクローズしない
- 「前半だけ良く後半が悪いもの」は意味がない。後半（現在に近い）を重視。後半で優位を見るときは前半平均 −100円以上を最低ラインに
- 高勝率の選び方は対象外（その候補群はすべて最良の一覧に含まれていたため）
- 偶然との明確な差は合格条件にしない（参考情報）。合格の目安は「前半・後半の両方で同じ向き、乖離幅を変えても崩れにくい」。最終判断は将来データ
- 2026/10/9以降のデータは、候補を確定するまで見ない（ld.bars の until='2026-10-09' を必ず使う）
- 進め方：D（指標単位の安定性）→ A（条件なし＋少数フィルター）→ C（投票方式）→ B（検証期間つき探索）。逆張り・順張りの両方
- 組み込む対策：区分の境目は前半のみで決める／コスト／極端な時期・外れ値／値動きの大きさ（ATR補正）／最悪の1回・最大DD

## 2. 候補群の検証（結論：最良を選ぶ方式は機能しない）
| | 逆張り | 順張り |
|---|---|---|
| 前半で選んだ候補群の前半の上乗せ（条件なし比） | +105円 | +120円 |
| その後半の上乗せ | ±0円 | −0.1円 |
- ①②③、p値・件数・勝率・プラス年・年ごとの安定性など、どの軸も後半を当てない（相関±0.06以内）。逆方向（後半で選び→前半）も同様（順張りでわずかに効果）
- 決済を固定すると前半・後半の上乗せに弱い相関（0.065、偶然は±0.03）。最良を選ぶとばらつきに埋もれる
- 偶然（条件をイベント単位で入れ替え）と比べ、基準を通過する候補群の数は同等以下
- 条件なしの順張り（0.6〜1.0%）は前半で決済を選んでも後半 +42〜+74円を維持。逆張りの条件なしは持続しない

## 3. D：単独指標の全区分の安定性（成果物 D_指標の安定性.xlsx）
- 1,944決済の平均で見ると、逆張りと順張りの上乗せは相関 −0.998（同じ乖離点で逆向きに入るため、1つの事実の裏表）
- 前半・後半で同じ向きの区分は全体で約49%（ほぼ半々）。前半tの中央値の絶対値≥2の区分（半数がATR系）だけ後半も約70%同じ向き
- 4つの確認（ATR補正・外れ値抑制・境目を前半で決定・1年除外）すべてで維持＋同じ向きの幅60%以上：逆張り90件、順張り80件
- 代表：5分/15分ATR上位10%（N>D）で逆張り −27〜−31円／順張り +26〜+30円。60分RSI上位10%（D>N）で逆張りは10年すべてマイナス。週足トレンド系（N>D）で逆張り +11〜+15円

## 4. A：条件なし＋少数フィルター（成果物 A_フィルター検証.xlsx）
- 乖離幅と決済を前半で1つ選ぶと後半は大きく目減り（例：逆張り条件なしD>N 前半+205円→後半−0.3円）。前半+20円以上の幅をまたいだ後半の中央値を主に見る
- 前半のみで選んだもの（後半＝純粋な確かめ）：
  - 順張り条件なし：後半 D>N +55円、両方の窓 +43円、N>D +24円（全幅でプラス）← 軸として最も確か
  - 順張り＋入る：5分ATR上位10%（両方の窓）：+48円 vs 同じ幅の条件なし +8.5円（幅0.03〜0.70%、23幅すべてプラス、後半年34件程度）
  - 順張り＋入る：15分ATR上位10%（N>D）：+35円 vs +11円。順張り＋避ける：15分MA並び=0（D>N）：+45円 vs +17円
  - 逆張り：N>D の入る：日足26MA乖離=5分割2 +10円、入る：60分RSI下位10% +7.5円 程度。コストで消える可能性大
  - 切替（逆張り基本＋避ける区分は順張り）：逆張り部分が弱く改善小
- すべてコスト未控除
