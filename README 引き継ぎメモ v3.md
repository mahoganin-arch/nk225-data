## 1. 決めた方針（このチャットで追加・変更したもの）
- コスト：FOREX.com Japan 225 のスプレッド13ptを標準。1回 = 13 ÷ 基準価格 × 68,800円（往復でスプレッド1回分）。前半平均 約39円、後半平均 約24円。感度として0pt・20ptも
- 最終的には前半の基準に依存し過ぎず、後半（現在の相場に近い期間）を重視したストラテジーにする。後半の中での前向き検証（2022-23→2024-26、1年ずつずらす検証）を加える。従来の評価（前半→後半）も残す（加えるのみ、分析は漏らさない）
- ATR区分の境目は (ウ) 直近N日の分布での順位（逐次更新）。値動きが荒いときの順張り(b)は乖離幅0.2%以上に限定
- 順張りと逆張りは別のストラテジー。入る乖離幅・相場環境・決済はそれぞれ自身の成績で選ぶ（裏返しで分析しない）。両者の関係を見るのは同時運用の重なりだけ
- 順張りの決済は「中間型」「後半型」の両方を残す
- 止める仕組みは損失の上限管理として付ける。評価は最大DDを主に（最大DDの減少／失う利益＝合計÷最大DD／最悪の年）
- CFDの日替わりは6:00。引けまで保有する決済は5:55（最後の足の始値）で決済する扱いに変更する（2024/11以降の夜間引け6:00が対象）
- 2026/10/9以降のデータは、候補を確定するまで見ない（until='2026-10-09'）

## 2. ステップ1：コスト反映（S1_コスト控除.xlsx）
- 13ptで残るのは D>N（＋両方の窓）の条件なし順張り 0.7〜1.2%。1.0%：前半で選んで後半 +47円/183件、損益分岐 約39pt
- N>D 単独は弱い。15分ATR上位10%（N>D）は後半 −143円で脱落
- 5分ATR上位10%の小さい幅（0.03〜0.15%）は損益分岐8〜16ptでコスト後マイナス。境目を前半固定にすると該当が2020・2024〜26年に偏る（2023年は1件）

## 3. ステップ2：順張りのルール化（S2_順張りルール化.xlsx）
- 選び方：単点（最良1点）と周辺（幅・損切り・利確・時間の各軸±1、最大81点の平均）。評価の形5つ：前半→後半／22-23→24-26／WF後半／WF全期間／WF直近3年
- 両方の窓・条件なし：5つの形すべてプラス（+18〜+69円/回、年約80件）。選ばれる幅はほぼ0.9%で安定。窓ごとに選んで足すより、まとめて選ぶ方が安定
- 決済は時期で形が変わる：前半型（損切りは基準を越えた位置・利確小さめ・120分）→ 後半型（戻り80〜90%で損切り・利確幅×1.5〜2・引けまで）
- 固定ルール（両方の窓、2025年までを見て選んだ形。2026年のみ未使用データ）：
  - 後半型 0.9%・戻り90%・利確×1.5・引け：後半 +85円（毎年プラス、2026年 +80円/104件）、前半 −27円、後半最大DD 約4,200円
  - 中間型 0.9%・戻り90%・利確×0.6・引け：後半 +68円、前半 ±0、後半勝率68%、後半最大DD 約2,900円
  - 前半型 0.8%・戻り125%・利確×0.75・120分：前半・後半とも +19円
- (b) ATR上位10%：形によって符号が入れ替わる。組み合わせると1窓の最悪が悪化し、上乗せは安定しない → 参考扱い
- 足の確認：全期間5分足で計算しても後半はほぼ同じ → 2022年以降の優位は相場の変化（足の違いではない）

## 4. ステップ3（S3_止める仕組み_逆張り_重なり.xlsx）
- ① 止める仕組み（事前固定：続いた率60窓、直近成績50回、日足ATR順位、日足ADX順位）：前向き検証の記録ではどれも「常に入る」を下回る。後半型の前半損失は減らせるが後半の利益も削る。「直近100回」が釣り合い最良（最大DD 9,900→4,200円）だが事前固定の50回ではなく、当てはめの可能性
- ② 逆張り（独立）：条件なしはコスト後、4つの分け方すべてで確かめる期間がマイナス。C（投票方式）は全決済平均の上乗せ +1〜+7円が残ることが多いがコストより小さい。B（2指標）は選ぶ期間の上位20組も確かめる期間でほぼ五分五分。残った候補は偶然の範囲。選ばれる決済は損切りなしが多く最悪 −2,000〜−2,800円
- ③ 重なり：0.2〜0.4%の逆張りと0.9%の順張りが同じ窓で入ると損益相関 −0.6〜−1.0（逆張りは平均 −260〜−300円）。合算で最悪の1窓が悪化する組が多い

## 5. 次にやること（合意済み）
### 5-1. 上限管理（順張り、中間型・後半型の両方）
- 候補は事前固定：DD基準（ピークからの損失 2,000／3,000／4,000円で停止）、直近成績基準（直近50／100回の合計がマイナスで停止）

- 評価：最大DDの減少、失う利益（合計÷最大DD）、最悪の年。前向き検証の記録と固定ルールの両方で
### 5-2. 漏れの対応：SQ・祝日・月末月初を条件として検証（順張り・逆張りとも）
- 曜日・時間帯は既に指標に含まれている。SQ週・SQ当日/前日・祝日前日/翌日・祝日取引中・月末/月初は最初の段階で参考の印としてだけ付けていた（cal.py, flags.py）
- これを F6 と同じ形の指標として加え、順張りの主軸（0.9%前後）と逆張りで、上乗せ・前向き検証を行う
### 5-3. 逆張りの新しい指標
- 窓の大きさ÷ATR、米国市場の動き（前夜の米国指数の騰落など。データの用意が必要）を加えて探す
### 5-4. 先物基準の窓（新しい定義、順張り・逆張りとも）
- 信号は先物、売買はCFD
- 基準：前セッションの先物の終値（例：朝の窓は夜間の引け、夕方の窓は日中の引け）
- 判定開始：先物の寄り（8:45／17:00）から。寄り前には入らない
- 入る：寄り後、基準から窓と同じ向きに乖離幅x%に届いたら入る。寄りの時点で既にx%以上離れていれば寄りですぐ入る。届かずに基準まで戻ったら「到達せず埋めた」としてその窓は入らない
- 乖離は窓と同じ向き（さらに離れる側）だけを数える
- データ：先物5分足（2017〜）、1分足（2023/10〜）。前半は5分足になる点は了承済み
- 現在の分析ではエントリーの約8割が寄り前 → 母集団が大きく変わる。現行（CFD基準）と比べる
- 要確認（次のチャットで最初に確認）：
  - CFDでの約定価格（先物が乖離幅に届いた時刻のCFD価格）
  - 利確・損切りの距離を先物とCFDのどちらの価格で判定するか（案：CFDのエントリー価格から同じ割合の距離で、CFDの価格で判定）
  - 窓の大きさの下限（寄りの窓がごく小さい窓も含めるか）
### 5-5. 決済時刻の変更
